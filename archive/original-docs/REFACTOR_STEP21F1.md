# Step 21F1 — Notification Cards UI

Version: 2.12.1

Scope is visual/action-layer only on top of 2.12.0.

- Preserves smart notification generation, SMS queue, dedupe, and scheduling logic.
- Restores premium notification cards with unread state, tone rail, category, time, booking/date/actor metadata.
- Adds contextual action buttons without changing notification data rules.
- Supports opening booking, payment, customer and message-log targets from cards/actions.
- Keeps existing SMS/WhatsApp/receipt actions for balance reminders.
- Dark mode and small-screen responsive styling included.
