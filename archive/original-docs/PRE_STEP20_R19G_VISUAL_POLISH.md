# Pre-Step20 r19g — Visual Polish

## النطاق
تحسين CSS وتنظيم بصري فقط للنوافذ التالية مع إضافات بسيطة مطلوبة لطلب الترقية:
- ملفي الشخصي
- سجل الرسائل
- طلب الترقية
- تواريخ الاشتراك وأزرار الترقية

## التغييرات
- ملف CSS مستقل: `assets/css/prestep20-r19g.css` لتقليل تراكم الترقيعات داخل الملفات القديمة.
- نظام بصري موحد للفاتح والداكن: أسطح، حدود، ظلال، حالات نجاح/تحذير/خطأ، Safe Area وتمرير الهاتف.
- إعادة صقل بطاقات الملف الشخصي والحقول والأزرار والإحصاءات مع Responsive أدق.
- إعادة تصميم سجل الرسائل: ملخص الحالات، بطاقات الرسائل، ألوان الحالات، زر إعادة المحاولة، Empty State.
- إعادة تصميم نافذة طلب الترقية إلى أقسام واضحة: الخطة، الدورة، وسيلة الدفع، رقم الحساب، الملاحظات، الإجمالي، زر الإرسال.
- إضافة رقم حساب قابل للنسخ لكل وسيلة دفع. القيم الحقيقية تُضبط يدويًا داخل `myfnt-defaults.js` ولا يتم اختراع أرقام.
- إضافة حقل ملاحظات لطلب الترقية وتخزينه داخل طلب الترقية المحلي.
- حفظ `paymentAccount` و`notes` داخل سجل طلب الترقية.
- عرض رقم الحساب والملاحظة في حالة وجود طلب ترقية قيد المراجعة.
- تحسين تنسيق تواريخ بداية/انتهاء الاشتراك وأزرار اختيار الترقية.

## إعداد أرقام المحافظ
داخل `assets/js/myfnt-defaults.js`:
- `upgradePaymentMethods[].account`
- `upgradePaymentMethods[].accountLabel`

اترك `account` فارغًا إذا لم يتم تحديد الرقم بعد؛ ستعرض الواجهة "رقم الحساب غير محدد" بدل رقم مزيف.
