# Myfnt 2.12.9 — Step21L Storage & User Sessions

## الهدف
تقليل الخلط بين Cache Storage وبيانات التطبيق الدائمة، إزالة تخزين الصور الكبيرة كـ Base64 داخل LocalStorage، وتحويل واجهة "المستخدمون والصلاحيات" إلى نموذج الحساب الرئيسي متعدد الجلسات/الأجهزة.

## ما كان يستهلك المساحة
1. Service Worker كان يضع screenshots الخاصة بتثبيت PWA ضمن precache ثم يعيد تخزين الصور الثابتة عبر stale-while-revalidate.
2. شعار الشركة كان يقبل ملفًا حتى 1MB ثم يحوله إلى Data URL/Base64 داخل إعدادات JSON؛ Base64 يزيد الحجم ويجعل تحديث الإعدادات يعيد كتابة الصورة كاملة.
3. الصورة الشخصية كانت تحفظ كـ Base64 داخل كائن المصادقة في LocalStorage.
4. navigator.storage.estimate() يعرض إجمالي مساحة origin: IndexedDB + LocalStorage + Cache Storage، لذلك كانت شاشة الصيانة توحي بأن كل الحجم "كاش" رغم أن معظم البيانات قد تكون حجوزات وسندات دائمة.

## الإصلاحات
### Media
- إضافة `assets/js/myfnt-media.js`.
- تخزين شعار الشركة والصورة الشخصية كـ Blob داخل IndexedDB (`myfnt-media-v1`).
- ضغط شعار الشركة إلى حد أقصى 320px قبل الحفظ.
- ضغط الصورة الشخصية إلى 256x256 JPEG.
- ترحيل تلقائي للشعار/الصورة القديمة من Data URL إلى IndexedDB عند أول تشغيل.
- عدم كتابة `blob:` URL المؤقت إلى إعدادات LocalStorage.
- دعم `blob:` عند رسم شعار الفاتورة والمعاينات.

### Service Worker
- إزالة `screenshot-mobile.png` و`screenshot-desktop.png` من precache.
- طلب screenshots بسياسة `cache: no-store` وعدم إدخالها إلى Cache Storage.
- إبقاء أيقونات التثبيت فقط ضمن الصور المسبقة؛ مجموعها قرابة 46KB.
- كاش إصدار جديد: `v2.12.9-step21l-storage-sessions-static`.

### شاشة الصيانة
- قياس Cache Storage الخاص بمايفنت بصورة مستقلة.
- عرض إجمالي مساحة الموقع بصورة منفصلة.
- توضيح أن الفرق يحتوي IndexedDB وLocalStorage وبيانات المستخدم الدائمة وليس كاشًا قابلاً للحذف.

### جلسات المستخدمين
- استبدال عنوان وقالب "المستخدمون والصلاحيات" بـ "جلسات المستخدمين".
- إزالة نموذج إضافة المستخدم، كلمة المرور الأولية، الدور، وشرائح الصلاحيات من التبويب.
- نموذج حساب رئيسي واحد مع عدة أجهزة/جلسات.
- كل جلسة تحصل على `sessionId`, `deviceId`, `deviceName`, `createdAt`, `lastSeenAt`.
- السماح بتسمية الجهاز بدون نافذة منبثقة/keyboard overlay؛ الاسم يعدل من داخل صفحة الجلسات.
- سجل محلي للجلسات المعروفة على هذا المتصفح، مرتب بآخر نشاط.
- إلغاء تقسيم الوصول المحلي Manager/Accountant؛ واجهة التوافق `OzanPermissions` تسمح للجلسة المسجلة للحساب الرئيسي فقط.
- منع تسجيل الدخول بحسابات الفريق القديمة؛ الحساب المرتبط كمالك للشركة فقط هو حساب تسجيل الدخول.
- جلسات الفريق القديمة النشطة يتم إبطالها عند بدء auth.
- سياسة الرسائل تقرأ الحساب الرئيسي فقط بدل أعضاء الأدوار القديمة.

## حدود النسخة المحلية
لا يستطيع متصفح بدون خادم رؤية جلسة موجودة على هاتف آخر فعليًا. سجل الجلسات الحالي يمثل الجلسات المعروفة لهذا المتصفح. بعد ربط PHP/API يمكن استخدام نفس حقول session/device لإظهار جميع الأجهزة وإنهاء جلسة عن بعد.

## التحقق
- جميع ملفات JavaScript اجتازت `node --check`.
- لا توجد Duplicate IDs في `index.html`.
- جميع موارد Service Worker موجودة.
- screenshots ليست ضمن precache.
- لا توجد عمليات `readAsDataURL` أو `toDataURL` متبقية لمسار تخزين الصور.
- الإصدار موحد: 2.12.9.
